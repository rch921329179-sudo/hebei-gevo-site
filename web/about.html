Anping County, Hebei · Since 2005

The factory behind the cages

Anping has made wire mesh for four hundred years. We have made poultry cages there for twenty, and we still weld, galvanise and load in the same plant rather than sub-contracting the parts that matter.

In-house

What we control in-house

  • Wire drawing and welding. Automatic welding lines, so mesh spacing is consistent set to set — the thing hand-welded cages get wrong.
  • Hot-dip galvanising. Our own tank. Galvanising after welding covers the weld points, which is where rust starts.
  • Frame fabrication and assembly. Cut, punched and trial-assembled before packing, so parts fit on site.
  • Loading and export documents. Handled by our own team, not an agent who has never seen the goods.
